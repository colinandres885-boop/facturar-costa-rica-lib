Los propietarios de la organización pueden conceder o revocar a un usuario el acceso para gestionar algunos o todos los GitHub Apps propiedad de la organización.

## Acerca de los administradores de GitHub App

Los propietarios de la organización y de la empresa pueden designar a otros usuarios u equipos de la organización como GitHub App administradores.
GitHub App los administradores pueden administrar la configuración de algunos o todos los GitHub App registros que pertenecen a la cuenta. El GitHub App rol de administrador no concede a los destinatarios acceso para instalar y desinstalar GitHub Apps en una organización  o empresa. Para obtener más información sobre la configuración de la aplicación específica que GitHub App los administradores pueden controlar, consulte [Modificación de un registro de aplicación de GitHub](/es/enterprise-server@3.22/apps/maintaining-github-apps/modifying-a-github-app-registration).

Para obtener más información sobre GitHub App los permisos de administrador, consulte [Roles en una organización](/es/enterprise-server@3.22/organizations/managing-peoples-access-to-your-organization-with-roles/roles-in-an-organization#github-app-managers).

## Conceder la capacidad para gestionar todos los GitHub Apps propiedad de la organización

Para asignar el rol de organización de App Manager a un usuario o equipo, consulte [Uso de los roles de la organización](/es/enterprise-server@3.22/organizations/managing-peoples-access-to-your-organization-with-roles/using-organization-roles#assigning-an-organization-role).

Usa la página de asignación de roles para ver a quién se le ha concedido este rol y cualquier otro rol en la organización. Los propietarios de la organización siempre pueden gestionar GitHub Apps y no aparecen en esta vista.
